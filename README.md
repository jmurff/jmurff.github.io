# DeeDogDevelopment website

The public site at https://jmurff.github.io/, served by GitHub Pages from this repository's `main` branch. Pushing to `main` publishes it; Pages can take a few minutes to update.

| Path | What's there |
| --- | --- |
| `index.html` | The DeeDogDevelopment home page, listing every app. |
| `<app>/index.html` | Each app's page: `game-closet`, `scorekeeper`, `tallyup-golf`, `rivalry`, `oven-time`, `yesterday`, `forks`. |
| `game-closet/privacy.html`, `game-closet/support.html` | The privacy policy and support pages App Store Connect links to. Keep these URLs. |
| `assets/` | The stylesheet, logo, favicon, and each app's icon and screenshots in `assets/<app>/`. |

The site used to live in the Game Closet repository under `docs/appstore/site` and was copied here by a publish script; its earlier history is there.

Commits here use the GitHub private email address, so the public history doesn't show a personal one.
